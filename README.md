# Etsy Tracker

Десктопна програма для Linux (Electron + React + TypeScript), яка стежить за магазинами Etsy
через **офіційний Etsy Open API v3**:

- додаєте посилання на магазини Etsy;
- програма зчитує всі активні товари кожного магазину — усе, що повертає API: назва, опис,
  ціна, теги, матеріали, стиль, хто/коли виготовив, час виготовлення, вага й розміри,
  персоналізація, відео, фото, дати, а також **популярність** (перегляди, скільки людей додали
  в обране, позиція серед рекомендованих) — і зберігає все в локальну базу SQLite (разом із
  повним JSON відповіді);
- фото товарів копіюються в локальне сховище **MinIO** (Docker), тож показуються навіть
  без CDN Etsy;
- кнопка **«Сканувати повторно»** показує, які товари **зʼявилися з минулого сканування**,
  а також які зникли, повернулися чи змінилися — і **що саме** змінилося (ціна, назва, опис,
  фото, теги, …); дані в базі й фото оновлюються;
- статистика магазину (продажі, відгуки, обране) і товарів з приростом від минулого
  сканування, сортування «Найпопулярніші», «Перегляди», «Ріст обраного»;
- історія всіх сканувань і перегляд кожного товару з галереєю фото, розділом «Деталі»,
  історією популярності (перегляди / обране / ранг за кожне сканування) та сирими даними API.

Перше сканування магазину — базове: воно лише запамʼятовує поточні товари.

## API-ключ Etsy

Програмі потрібен ваш власний ключ — він вводиться в **Налаштуваннях** програми і
зберігається лише на цьому компʼютері (зашифрованим системним сховищем ключів, якщо воно
доступне).

1. Увійдіть на Etsy і зареєструйте застосунок: https://www.etsy.com/developers/register
   Для відстеження чужих магазинів обирайте **Personal App**.
2. На сторінці https://www.etsy.com/developers/your-apps натисніть іконку ока й скопіюйте
   **Keystring** та **Shared secret** — потрібні обидва (Etsy з 9.02.2026 вимагає заголовок
   `x-api-key: keystring:shared_secret`).
3. Ключ запрацює лише після схвалення застосунку Etsy (Personal App проходить ручну перевірку).
4. Вставте обидва значення в Налаштуваннях і натисніть «Перевірити ключ».

Ліміти запитів залежать від вашого ключа; залишок денного ліміту показується внизу бічної
панелі. Одне сканування коштує приблизно 2 запити на кожні 100 товарів (сторінки + деталі:
перегляди повертає лише запит деталей) плюс 1 запит магазину.

## Сховище фото (MinIO)

```bash
docker compose up -d     # у теці проєкту (вихідний код etsy-tracker, де лежить docker-compose.yml)
```

Встановлена програма (AppImage/deb) не містить `docker-compose.yml`; без вихідного коду
той самий контейнер можна запустити так:

```bash
docker run -d --name etsy-tracker-minio --restart unless-stopped \
  -p 127.0.0.1:9100:9000 -p 127.0.0.1:9101:9001 -v etsy-tracker-minio-data:/data \
  -e MINIO_ROOT_USER=etsytracker -e MINIO_ROOT_PASSWORD=<ваш-пароль> \
  -e MINIO_API_CORS_ALLOW_ORIGIN=http://127.0.0.1:9101 \
  minio/minio:RELEASE.2025-09-07T16-13-09Z server /data --console-address :9001
```

- S3 API: `http://127.0.0.1:9100`, консоль: http://127.0.0.1:9101 (логін і пароль —
  `MINIO_ROOT_USER` / `MINIO_ROOT_PASSWORD`, типово `etsytracker` / `etsytracker-minio-secret`).
- Типові налаштування програми збігаються з `docker-compose.yml`, тож нічого вводити не треба.
  **Але типовий пароль загальновідомий** (він є в цьому репозиторії), тож Налаштування
  показують попередження, доки ви не задасте власний. S3 API доступний лише з 127.0.0.1, а CORS
  дозволяє браузерні запити тільки з консолі (`MINIO_CORS_ALLOW_ORIGIN`). Щоб змінити облікові
  дані чи порти, скопіюйте `.env.example` у `.env`, змініть значення,
  перезапустіть контейнер і введіть ті самі значення в **Налаштування → «Сховище зображень
  (MinIO)»** (там же — «Перевірити зʼєднання» та вимкнення сховища). Secret key зберігається
  зашифрованим системним сховищем ключів.
- Бакет (`etsy-tracker`) програма створює сама. Ключі обʼєктів:
  `shops/{shop_id}/listings/{listing_id}/{listing_image_id}/{fullxfull|570xN}.jpg`.
- Фото копіюються у фоні після кожного сканування; якщо MinIO не запущений, сканування все одно
  проходить, а фото чекають наступного разу (або кнопки «Синхронізувати фото»). Поки фото не
  скопійоване, воно показується з CDN Etsy. «Синхронізувати фото» також перевіряє, що вже
  скопійовані фото справді є в бакеті (після зміни бакета чи очищення тому вони копіюються
  знову); зміна адреси або бакета в Налаштуваннях ставить усі фото в чергу на копіювання.
- MinIO Inc. більше не публікує образи на Docker Hub. Якщо `docker compose up -d` не може
  завантажити `minio/minio:RELEASE.2025-09-07T16-13-09Z`, вкажіть у `.env`
  `MINIO_IMAGE=pgsty/minio:RELEASE.2026-08-04T00-00-00Z` (спільнотна збірка).

## Запуск

Потрібні Node.js 22.13+ (вбудований `node:sqlite` без прапорців) і npm.

```bash
npm install
npm run dev        # запуск у режимі розробки
npm test           # тести (Vitest)
npm run build      # перевірка типів + збірка в out/
npm run dist       # AppImage + deb у dist/
bash scripts/install-desktop.sh   # додати зібраний AppImage в меню застосунків з іконкою
```

Дані зберігаються в `~/.config/etsy-tracker/` (`etsy-tracker.db`, `settings.json`), фото —
у томі Docker `etsy-tracker_minio-data`.

## Умови Etsy API

Програма показує дані на момент останнього сканування; умови Etsy вимагають, щоб показані
дані товарів були не старші за 6 годин, тому програма підказує просканувати повторно.
Фото копіюються лише у ваш локальний MinIO для особистого використання; сховище можна вимкнути
в Налаштуваннях — тоді фото знову показуються напряму з CDN Etsy.
