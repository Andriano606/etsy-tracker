# Etsy Tracker

Десктопна програма для Linux (Electron + React + TypeScript), яка стежить за магазинами Etsy
через **офіційний Etsy Open API v3**:

- додаєте посилання на магазини Etsy;
- програма зчитує всі активні товари кожного магазину — усе, що повертає API: назва, опис,
  ціна, теги, матеріали, стиль, хто/коли виготовив, час виготовлення, вага й розміри,
  персоналізація, відео, фото, дати, а також **популярність** (перегляди, скільки людей додали
  в обране, позиція серед рекомендованих) — і зберігає все в локальну базу SQLite (разом із
  повним JSON відповіді);
- фото товарів копіюються в локальне сховище **MinIO** (Docker), тож показуються навіть
  без CDN Etsy;
- кнопка **«Сканувати повторно»** показує, які товари **зʼявилися з минулого сканування**,
  а також які зникли, повернулися чи змінилися — і **що саме** змінилося (ціна, назва, опис,
  фото, теги, …); дані в базі й фото оновлюються;
- статистика магазину (продажі, відгуки, обране) і товарів з приростом від минулого
  сканування, сортування «Найпопулярніші», «Перегляди», «Ріст обраного»;
- кнопка **«📊 Статистика»** у кожного магазину — графіки між скануваннями за весь час / 90 / 30 / 7 днів:
  продажі (і продажі за день), обране, активні товари, відгуки (по тижнях і місяцях за всю історію),
  перегляди й обране всіх товарів, зміни за сканування, топ товарів за ростом (зміна за 90 / 30 / 7 днів
  рахується від останнього сканування перед періодом);
- **відгуки** кожного магазину (усі, з текстом, оцінкою, мовою, датою й фото покупця) — найкращий
  доступний показник того, як часто купують товар (продажі окремих товарів чужих магазинів Etsy не
  показує): на картці товару ⭐ середня оцінка (кількість) і «+N» нових відгуків з минулого
  сканування, сортування «Найбільше відгуків» і «Ріст відгуків», група «Нові відгуки» в результатах
  сканування, розділ «Відгуки» у вікні товару;
- **ціна як на сайті** для покупця з вибраної країни (Налаштування → «Країна покупця», типово UA):
  з ПДВ і з активною знижкою — «1,20 USD ~~3,00 USD~~ −60%»; базова ціна продавця теж зберігається.
  **Акції** відстежуються між скануваннями (коли почалася / закінчилася, %, ціни), сортування
  «Найбільша знижка», фільтр «Зі знижкою», група «Акції» в результатах сканування, графік
  «Товарів зі знижкою» у Статистиці;
- історія всіх сканувань і перегляд кожного товару з галереєю фото, розділом «Деталі»,
  історією популярності (перегляди / обране / ранг / відгуки за кожне сканування), історією цін
  і акцій та сирими даними API;
- **«Мій магазин»**: вхід в Etsy, ваш магазин у списку з міткою «мій», редагування й створення
  лістингів (з фото та файлами) і текстів магазину;
- **MCP-сервер для Claude** (кнопка «MCP» угорі бічної панелі): будь-який Claude — Claude Code,
  Claude Desktop чи інший MCP-клієнт — може **читати** всі зібрані дані: магазини, товари, ціни,
  знижки, відгуки, фото, історію змін і статистику. Для Claude це нейтральний каталог «магазинів»
  і «товарів», без назви майданчика.

Перше сканування магазину — базове: воно лише запамʼятовує поточні товари.

## API-ключ Etsy

Програмі потрібен ваш власний ключ — він вводиться в **Налаштуваннях** програми і
зберігається лише на цьому компʼютері (зашифрованим системним сховищем ключів, якщо воно
доступне).

1. Увійдіть на Etsy і зареєструйте застосунок: https://www.etsy.com/developers/register
   Для відстеження чужих магазинів обирайте **Personal App**.
2. На сторінці https://www.etsy.com/developers/your-apps натисніть іконку ока й скопіюйте
   **Keystring** та **Shared secret** — потрібні обидва (Etsy з 9.02.2026 вимагає заголовок
   `x-api-key: keystring:shared_secret`).
3. Ключ запрацює лише після схвалення застосунку Etsy (Personal App проходить ручну перевірку).
4. Вставте обидва значення в Налаштуваннях і натисніть «Перевірити ключ».

Ліміти запитів залежать від вашого ключа; залишок денного ліміту показується внизу бічної
панелі. Одне сканування коштує приблизно 2 запити на кожні 100 товарів (сторінки + деталі:
перегляди повертає лише запит деталей) плюс 1 запит магазину.

## Чому ціна відрізняється від сайту

API Etsy повертає у полі `price` **базову ціну продавця** — без ПДВ і без знижок. Сайт показує
покупцеві іншу ціну: з ПДВ його країни (у Великій Британії — ще й з доставкою) та з активною
акцією. Приклад: базова ціна 2,50 $ → з ПДВ України 20 % = 3,00 $ → зі знижкою −60 % = 1,20 $
(«Now Price: USD 1.20, Original Price: USD 3.00»).

Тому програма додатково просить у Etsy ціну для покупця (`includes=BuyerPrice` +
`buyer_country`, у тому ж запиті деталей — без додаткових запитів) для країни з Налаштувань →
«Країна покупця» (типово **UA**). Нова країна застосовується з наступного сканування. Картка
показує ціну зі знижкою, перекреслену стару ціну, «−60%» і код країни; підказка — базову ціну
продавця. Якщо Etsy не віддає ціну для покупця з вашим ключем (або для вибраної країни),
сканування працює як раніше, а показується базова ціна (з поясненням у заголовку магазину); іншу
країну програма спробує знову, не чекаючи перезапуску. Зміна ціни покупця чи знижки не
вважається «зміною товару» — акції мають окрему історію; зміна базової ціни продавця, як і
раніше, показується як «ціна».

## Відгуки

Після кожного успішного сканування програма у фоні синхронізує відгуки магазину (один запит
Etsy повертає до 100 відгуків усього магазину). Помилка відгуків ніколи не зриває сканування
товарів — вона лише показується в заголовку магазину.

- **Перший раз** завантажується вся історія: ≈1 запит на 100 відгуків (магазин з ~9 300 відгуками —
  ≈94 запити). Щоб не витратити денний ліміт, один прохід робить щонайбільше 300 запитів і
  зупиняється, коли до кінця денного ліміту лишається менше 1 000 запитів; велика історія
  догружається з наступними скануваннями (або кнопкою «Синхронізувати відгуки»). Поки історія
  неповна, кількості показуються як «≥ N», а в заголовку — «Відгуки: 3 200 / ~9 300».
- **Далі** — кожне сканування перечитує відгуки за останні 7 днів (перекриття, щоб побачити
  відредаговані відгуки) плюс нові: ≈1 запит на кожні 100 відгуків, створених за цей час (для
  магазину з ~9 300 відгуками — зазвичай 1 запит, для дуже великого — десяток).
- Відгук, який видалили на Etsy, поки історія догружається, не зсуває решту: жоден відгук не
  пропускається. Видалені на Etsy відгуки з бази не прибираються.
- «Нові» — лише ті, що зʼявилися після початку відстеження; старі відгуки з історії ніколи не
  вважаються новими.
- Фото до відгуків копіюються в MinIO (`shops/{shop_id}/reviews/{ключ_відгуку}/fullxfull.jpg`);
  якщо Etsy перестає повертати фото (налаштування приватності покупця), копія видаляється.

## Сховище фото (MinIO)

```bash
docker compose up -d     # у теці проєкту (вихідний код etsy-tracker, де лежить docker-compose.yml)
```

Встановлена програма (AppImage/deb) не містить `docker-compose.yml`; без вихідного коду
той самий контейнер можна запустити так:

```bash
docker run -d --name etsy-tracker-minio --restart unless-stopped \
  -p 127.0.0.1:9100:9000 -p 127.0.0.1:9101:9001 -v "$HOME/.local/share/etsy-tracker/minio":/data \
  -e MINIO_ROOT_USER=etsytracker -e MINIO_ROOT_PASSWORD=<ваш-пароль> \
  -e MINIO_API_CORS_ALLOW_ORIGIN=http://127.0.0.1:9101 \
  minio/minio:RELEASE.2025-09-07T16-13-09Z server /data --console-address :9001
```

- S3 API: `http://127.0.0.1:9100`, консоль: http://127.0.0.1:9101 (логін і пароль —
  `MINIO_ROOT_USER` / `MINIO_ROOT_PASSWORD`, типово `etsytracker` / `etsytracker-minio-secret`).
- Типові налаштування програми збігаються з `docker-compose.yml`, тож нічого вводити не треба.
  **Але типовий пароль загальновідомий** (він є в цьому репозиторії), тож Налаштування
  показують попередження, доки ви не задасте власний. S3 API доступний лише з 127.0.0.1, а CORS
  дозволяє браузерні запити тільки з консолі (`MINIO_CORS_ALLOW_ORIGIN`). Щоб змінити облікові
  дані чи порти, скопіюйте `.env.example` у `.env`, змініть значення,
  перезапустіть контейнер і введіть ті самі значення в **Налаштування → «Сховище зображень
  (MinIO)»** (там же — «Перевірити зʼєднання» та вимкнення сховища). Secret key зберігається
  зашифрованим системним сховищем ключів.
- Бакет (`etsy-tracker`) програма створює сама. Ключі обʼєктів:
  `shops/{shop_id}/listings/{listing_id}/{listing_image_id}/{fullxfull|570xN}.jpg`, фото відгуків —
  `shops/{shop_id}/reviews/{ключ_відгуку}/fullxfull.jpg`.
- Фото копіюються у фоні після кожного сканування; якщо MinIO не запущений, сканування все одно
  проходить, а фото чекають наступного разу (або кнопки «Синхронізувати фото»). Поки фото не
  скопійоване, воно показується з CDN Etsy. «Синхронізувати фото» також перевіряє, що вже
  скопійовані фото справді є в бакеті (після зміни бакета чи очищення тому вони копіюються
  знову); зміна адреси або бакета в Налаштуваннях ставить усі фото в чергу на копіювання.
- MinIO Inc. більше не публікує образи на Docker Hub. Якщо `docker compose up -d` не може
  завантажити `minio/minio:RELEASE.2025-09-07T16-13-09Z`, вкажіть у `.env`
  `MINIO_IMAGE=pgsty/minio:RELEASE.2026-08-04T00-00-00Z` (спільнотна збірка).

## MCP: дані для Claude

Кнопка **«MCP»** угорі бічної панелі відкриває налаштування локального MCP-сервера:

1. Позначте «Увімкнути MCP-сервер» і натисніть «Зберегти» (типовий порт `9102`; 9100/9101
   зайняті MinIO).
2. Скопіюйте готову команду кнопкою «Копіювати» і вставте в термінал:
   `claude mcp add --transport http --scope user shop-catalog http://127.0.0.1:9102/mcp --header "Authorization: Bearer …"`.
   Там же є `.mcp.json` для проєкту і конфіг для Claude Desktop (через `npx mcp-remote`).
3. У Claude Code перевірте `/mcp`: сервер `shop-catalog` має бути «connected». Далі просто
   питайте: «що нового в магазинах?», «найпопулярніші товари зі знижкою», «покажи фото
   товару…», «які товари найчастіше хвалять у відгуках?».

Що варто знати:

- **Читання** — 13 інструментів: `list_stores`, `get_store`, `search_products`,
  `get_product`, `get_product_history`, `list_snapshots`, `get_snapshot_changes`,
  `list_reviews`, `get_store_stats`, `get_product_image`, `get_review_photo`, `get_store_logo` (логотип або банер магазину), `get_product_video_preview` (кадр-прев’ю відео товару).
- **Нейтральні дані.** Назви й опис інструментів, поля відповідей («store», «product»,
  «snapshot» = сканування, «discount» = акція, «customer price» = ціна для покупця) не
  згадують майданчик. Посилання на нього, адреси CDN і сирий JSON API не віддаються; слово
  «Etsy» і посилання в текстах самих товарів, політик і відгуків замінюються на
  «marketplace» / «[link]». Розумна модель усе ж може *здогадатися* про джерело за змістом
  (тип товарів, «обране», рекомендовані позиції). Прямо їй про нього ніхто не каже.
- **Лише цей комп’ютер.** Сервер слухає тільки `127.0.0.1`, вимагає токен (зберігається
  зашифрованим, як API-ключ) і відхиляє запити з чужих сайтів (перевірки Host/Origin).
  Він працює, лише поки відкрита програма.
- **Свій магазин через Claude.** Якщо ви увійшли у свій магазин («Мій магазин»), Claude бачить його
  з позначкою `is_mine` і може читати всі свої лістинги, зокрема чернетки (`list_my_products`),
  шукати категорії й варіанти полів. Змінювати магазин він може лише тоді, коли в модалці MCP
  увімкнено **«Дозволити Claude змінювати мій магазин»**: створювати лістинги з фото й файлами
  (`create_product`; файли — шляхом на диску або вмістом), редагувати їх, вмикати й вимикати
  (`update_my_product`), додавати фото й файли (`add_product_media`) і змінювати тексти магазину
  (`update_my_store`). Claude Code однаково питає дозволу на кожен такий виклик.
- **Новий токен** (кнопка в модалці) одразу відключає всіх старих клієнтів. Оновіть їх
  командою «якщо вже додано»: вона видаляє старий запис і додає новий.

## Мій магазин (редагування свого магазину)

Кнопка **«✏️ Мій магазин»** у бічній панелі дає змогу змінювати **власний** магазин Etsy:
лістинги в будь-якому стані (назва, опис, теги, матеріали, автопродовження, увімкнути / вимкнути /
опублікувати) і тексти магазину (заголовок, оголошення, повідомлення покупцям).

Вхід відбувається один раз (OAuth): повторно входити доведеться приблизно раз на 90 днів.

1. На https://www.etsy.com/developers/your-apps у налаштуваннях свого застосунку додайте
   адресу повернення `https://localhost:3003/callback` (Etsy приймає лише `https://`).
2. У програмі: «Мій магазин» → «Увійти через Etsy». У браузері натисніть «Allow Access».
3. Браузер перейде на `https://localhost:3003/callback?code=…` і покаже помилку — так і має бути.
   Скопіюйте цю адресу з адресного рядка, вставте в програму й натисніть «Завершити вхід».

Після входу ваш магазин з’являється у списку магазинів з міткою **«мій»** і стежиться, як і решта.
У його шапці є кнопки **«＋ Новий лістинг»** і **«✏️ Керувати»**.

**Чернетки в програмі.** Новий лістинг спершу зберігається **в програмі** як чернетка («＋ Новий лістинг»
або «📝 Чернетки»). Ви переглядаєте й правите її, а тоді натискаєте «Надіслати на Etsy як чернетку»
або «Надіслати й опублікувати». Claude через MCP теж може готувати такі чернетки (`prepare_product`):
вони з’являються в «📝 Чернетках» з позначкою «від Claude», і ви самі вирішуєте, що з ними робити.
Для цього не потрібен дозвіл «змінювати мій магазин», бо на Etsy нічого не надсилається.

**Поля лістингу:** тип (цифровий або фізичний), назва, опис, ціна, кількість, категорія (пошук
за словом), хто і коли виготовив, теги, матеріали, фото (до 10, перше — головне) і, для цифрових
товарів, файли для покупця (до 5, кожен до 20 МБ). Можна зберегти чернетку або одразу
опублікувати. Для фізичного товару потрібен профіль доставки (його створюють на Etsy).

Зміни потрапляють на Etsy одразу. У даних стеження вони з’являться після наступного сканування.
Публікація чернетки чи прострочного лістингу коштує звичайні $0.20 (програма попереджає).
Ціну й кількість поки що змінюють на сайті Etsy: вони зберігаються в «інвентарі» разом із варіаціями.

## Усе інше з Etsy API

Програма покриває **всі методи** офіційного Etsy API:

- **🔎 Пошук по Etsy** (бічна панель): пошук по всьому маркетплейсу, не лише по ваших магазинах.
  Ключові слова, категорія, ціна, сортування, розташування; підсумок цін, «Стежити за магазином».
- **ℹ️ Більше** (шапка будь-якого магазину): розділи магазину, рекомендовані товари, політики
  повернення. У вікні товару — живі атрибути, фото й відео, персоналізація, переклади, фото
  варіацій, вартість доставки, відгуки.
- **Мій магазин** (після входу), вкладки:
  - «Ціни й залишки»;
  - «Розділи», «Доставка», «Обробка», «Повернення», «Свята», «Партнери»;
  - «Замовлення» (з «Позначити відправленим») і «Фінанси» (журнал балансу, платежі);
  - «Акаунт».
- **У редакторі свого лістингу** — секції:
  - «Ціна, кількість і варіації», «Фото варіацій»;
  - «Фото, відео й файли»;
  - «Атрибути», «Персоналізація», «Переклади»;
  - «Розділ магазину», «Продажі»;
  - «Небезпечна зона» (видалення лістингу).
- **Дозволи входу.** Для замовлень, фінансів, видалення лістингів, email і адрес програма тепер
  просить більше дозволів. Якщо ви входили раніше, «Мій магазин» підкаже, що треба вийти й увійти ще раз.
- **MCP:** усе це доступне й Claude — 97 інструментів, нейтральні назви. Зміни лише з дозволом
  «змінювати мій магазин». Контакти покупців (email, вулиця) Claude отримує тільки на явний запит.

## Запуск

Потрібні Node.js 22.13+ (вбудований `node:sqlite` без прапорців) і npm.

```bash
npm install
npm run dev        # запуск у режимі розробки
npm test           # тести (Vitest)
npm run build      # перевірка типів + збірка в out/
npm run dist       # AppImage + deb у dist/
bash scripts/install-desktop.sh   # додати зібраний AppImage в меню застосунків з іконкою
```

Дані зберігаються в `~/.config/etsy-tracker/` (`etsy-tracker.db`, `settings.json`), фото —
у теці `~/.local/share/etsy-tracker/minio` (змінюється через `MINIO_DATA_DIR` у `.env`).
Це звичайна тека на диску, а не том Docker: Docker Desktop тримає томи на власному
віртуальному диску фіксованого розміру, і коли він заповнюється, MinIO відмовляється
зберігати фото (`XMinioStorageFull`).

## Умови Etsy API

Програма показує дані на момент останнього сканування; умови Etsy вимагають, щоб показані
дані товарів були не старші за 6 годин, тому програма підказує просканувати повторно.
Фото копіюються лише у ваш локальний MinIO для особистого використання; сховище можна вимкнути
в Налаштуваннях — тоді фото знову показуються напряму з CDN Etsy.
